# 우리 아빠

웹 브라우저에서 바로 플레이하는 비주얼 노벨입니다. 전 18장, 선택지 74개, 고른 갈래에 따라 엔딩 넷. 한 번 플레이에 대사 약 1,800줄. 화면 전체를 쓰는 몰입형 화면, 대사마다 바뀌는 표정(인물 12세트 × 8종), 대사에 맞춰 바뀌는 장면 그림 74장, 계절에 따라 내리는 낙엽·진눈깨비·비·눈. 타이틀 화면, 이어하기, 설정, 엔딩과 장면 갤러리가 있습니다.

- 플레이: https://kosj.github.io/novel-farther/
- 실행: `index.html`을 브라우저로 열면 됩니다. 빌드 과정이 없습니다.
- 그림: `images/` (VARCO로 생성), 소리: `audio/` (ElevenLabs로 생성, 빗소리와 천둥은 브라우저에서 합성)
- 대본, 장면, 음원 연결은 모두 `index.html` 안의 `S`, `BG`, `BGM`, `SFX`, `ENDS` 목록에서 고칩니다.

## 엔딩

선택지마다 ‘지수에게 낸 용기’와 ‘서윤에게 솔직했던 순간’이 조용히 기록됩니다. 16장 가모가와 강변에서 고백했는지, 그때까지 용기가 쌓였는지, 딸에게 솔직했는지에 따라 18장이 갈라집니다.

- A 우리 가족
- B 두 사람의 봄
- C 우리 둘
- D 착한 아저씨

찾은 엔딩은 갤러리에 모이고, 아직 지나지 않은 장은 장 이동에서 잠겨 있습니다.

## 조작

- 화면을 누르거나 Space·Enter: 다음 대사
- 오른쪽 위 톱니 또는 Esc: 메뉴 (자동 넘김, 지난 대사, 그림만 보기, 장 이동, 소리, 글자 속도)
- 키보드 A 자동 넘김, L 지난 대사, H 그림만 보기
