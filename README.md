# 우리 아빠

웹 브라우저에서 바로 플레이하는 비주얼 노벨입니다. 전 18장, 선택지 65개. 한 번 플레이에 대사 약 1,650줄. 화면 전체를 쓰는 몰입형 화면, 대사마다 바뀌는 표정(인물 10세트 × 8종), 서윤이 나이에 맞춰 바뀌는 배경 37장. 타이틀 화면, 이어하기, 설정, 장면 갤러리가 있습니다.

- 플레이: https://kosj.github.io/novel-farther/
- 실행: `index.html`을 브라우저로 열면 됩니다. 빌드 과정이 없습니다.
- 그림: `images/` (VARCO로 생성), 소리: `audio/` (ElevenLabs로 생성)
- 대본, 장면, 음원 연결은 모두 `index.html` 안의 `S`, `BG`, `SPRITE`, `BGM`, `SFX` 목록에서 고칩니다.

## 조작

- 화면을 누르거나 Space·Enter: 다음 대사
- 오른쪽 위 톱니 또는 Esc: 메뉴 (자동 넘김, 지난 대사, 그림만 보기, 장 이동, 소리, 글자 속도)
- 키보드 A 자동 넘김, L 지난 대사, H 그림만 보기
