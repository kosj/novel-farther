# 우리 아빠

웹 브라우저에서 바로 플레이하는 비주얼 노벨입니다. 전 18장, 선택지 65개. 한 번 플레이에 대사 약 1,650줄. 타이틀 화면, 이어하기, 설정, 장면 갤러리가 있습니다.

- 플레이: https://kosj.github.io/novel-farther/
- 실행: `index.html`을 브라우저로 열면 됩니다. 빌드 과정이 없습니다.
- 그림: `images/` (VARCO로 생성), 소리: `audio/` (ElevenLabs로 생성)
- 대본, 장면, 음원 연결은 모두 `index.html` 안의 `S`, `BG`, `SPRITE`, `BGM`, `SFX` 목록에서 고칩니다.
